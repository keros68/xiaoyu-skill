# Optional Generated Illustrations

Read only when a conceptual scene or object would be clearer with a generated illustration and no suitable existing asset is available. Image2 or another available image-generation tool is optional; it is not a prerequisite for any figure role.

## Appropriate use

Generate conceptual objects, scenes, cutaways, or process illustrations when they contribute explanatory information. Use real project sources for measured imagery, maps, experimental photographs, and quantitative plots. Never synthesize apparent observational evidence to fill a missing source.

If a figure looks generic, first revisit content, module hierarchy, and representations. Do not infer a need for generated art from a request to remove an AI-like appearance. Native vector drawing and existing assets remain valid choices.

Confirm the required subject, scientific meaning, and style from the content brief. Follow the user's reference without another approval step when direction is already clear. Record the generated origin and mark schematic content where it could be mistaken for an observation.

## Generation and assembly

Request only the objects needed, either individually or as a sheet of separable elements. No fixed element count is required. Choose a style that fits the figure: technical line art, vector-like illustration, cutaway, or another treatment supported by the reference. Earth-science subject matter alone does not imply watercolor or 3D.

A useful prompt specifies:

- the conceptual subject and scientifically necessary features;
- the desired visual treatment and consistency with existing assets;
- complete isolated objects, with space for cropping if using a sheet;
- no baked-in labels, numbers, arrows, or decorative background when these belong in editable layers.

For an element sheet, split the used objects into separate images, preserve the original, and inspect for clipped edges, halos, or fragments. Do not insert the whole sheet as the finished figure. Preserve transparent edges when appropriate. If removing a chroma-key background with a script, use a sufficiently wide integer type before squaring color differences.

Embed the final assets and add editable labels, connectors, and structural objects. Review generated features against the intended science; attractive rendering is not evidence of correctness. Report generated origin and relevant editing limitations without treating image counts as a quality score.
